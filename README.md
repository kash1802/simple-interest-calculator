
# Simple Interest Calculator

## Introduction
A Simple Interest Calculator is a basic application used to calculate the simple interest on a given principal amount.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

Where:
- Principal (P) = Initial amount
- Rate (R) = Annual interest rate
- Time (T) = Time period in years

## Example
Principal = 10000
Rate = 5%
Time = 2 years

Simple Interest = (10000 × 5 × 2) / 100

Simple Interest = 1000

Total Amount = 11000

## Algorithm
1. Start
2. Enter the principal amount.
3. Enter the rate of interest.
4. Enter the time period.
5. Calculate simple interest using the formula.
6. Display the simple interest.
7. Display the total amount.
8. Stop.

## Technologies Used
- Basic Programming Concepts
- Arithmetic Operations

## Conclusion
The Simple Interest Calculator helps users calculate interest easily using the principal amount, interest rate, and time period.
